### ⚙️ [Software PEGA](https://github.com/atmoschem/pega)

Software científico desenvolvido no âmbito do Projeto O₃ MOVER, voltado à elaboração de inventários de emissões atmosféricas.

A ferramenta tem como objetivo automatizar o cálculo, o processamento e a distribuição de emissões de poluentes, contribuindo para a padronização, a eficiência e a reprodutibilidade de estudos científicos.

Inicialmente desenvolvido na linguagem R, o software evoluiu para uma aplicação web em Python, com arquitetura integrada entre frontend e backend, buscando ampliar sua acessibilidade e facilitar sua utilização por pesquisadores.

**Principais funcionalidades:**

- Importação e validação de bases de dados;
- Cálculo automatizado de emissões atmosféricas;
- Processamento e análise de dados ambientais;
- Especiação química de poluentes;
- Distribuição temporal e espacial de emissões;
- Geração de gráficos e visualização de resultados;
- Exportação de dados em formatos científicos;
- Desenvolvimento de funcionalidades para integração com o WRF-Chem;
- Interface web para execução e acompanhamento dos processos.

`R · Python · FastAPI · Shiny · HTML · CSS · JavaScript · Docker · Análise de Dados`

🟡 **Status:** Em desenvolvimento.
